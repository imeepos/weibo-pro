# 与 AI 高效对话的艺术

> 一本关于提示词工程和对话策略的全面指南

## 内容简介

本书旨在帮助普通用户掌握与大语言模型（如 ChatGPT、Claude 等）高效对话的技巧。从基础概念到高级策略，通过大量实例和实用模板，让你能够充分发挥 AI 的潜力。

## 目标读者

- 日常使用 ChatGPT、Claude 等 AI 助手的普通用户
- 希望提高 AI 对话效率的知识工作者
- 对提示词工程感兴趣的初学者
