# 第七章：问题排查

## 7.1 回答不准确的应对

### 识别不准确回答

**常见信号**：
- 与常识或已知事实不符
- 前后矛盾
- 过于绝对化
- 缺乏具体来源

### 应对策略

**明确指出问题**：
```
你的回答中提到 [内容]，但这与我的理解不同。

根据 [来源/事实]，实际情况是 [正确信息]。

请核实并重新回答。
```

**要求提供依据**：
```
你得出的结论是 [结论]。

请说明：
1. 这个结论的依据是什么？
2. 有哪些可能的不确定性？
3. 建议如何验证？
```

**多角度验证**：
```
对于这个问题，请：
1. 先给出你的答案
2. 说明可能的错误来源
3. 提供验证方法
4. 如果不确定，请明确指出
```

### 事实核查流程

```
[问题]

请按以下格式回答：

结论：[你的结论]

置信度：[高/中/低]

依据：[列出依据]

验证建议：[如何验证这个结论]

如果置信度为低，请说明需要什么额外信息。
```

## 7.2 理解偏差的修正

### 常见理解偏差类型

| 偏差类型 | 表现 | 修正方法 |
|---------|------|---------|
| 字面理解 | 按字面意思理解隐喻 | 明确说明真实意图 |
| 语境缺失 | 忽略隐含上下文 | 补充背景信息 |
| 范围错误 | 理解范围过宽/窄 | 明确边界条件 |
| 重点偏移 | 关注非核心内容 | 强调关键要求 |

### 修正方法

**重新表述**：
```
我刚才的提问可能不够清晰。

让我重新表达：
1. 核心问题是：[明确问题]
2. 重点是：[关键点]
3. 不需要：[排除内容]

请基于这些澄清重新回答。
```

**对比式澄清**：
```
我想要的是 A 而非 B：

A: [你想要的]
B: [你得到的]

请调整回答，更接近 A。
```

**渐进式引导**：
```
我们好像有些理解偏差。

让我先问一个更基础的问题：[简化问题]

基于你对这个问题的回答，
我再逐步引导到我的真实需求。
```

## 7.3 输出质量的提升

### 质量诊断

```
你刚才的回答：[复制回答]

请自我评估：
1. 是否完全回答了问题？
2. 哪些部分可以更具体？
3. 哪些内容可能是冗余的？
4. 如何提升回答的价值？

基于评估，请给出改进版回答。
```

### 精确度提升

**增加约束**：
```
你的回答太宽泛了。

请重新回答，并满足：
1. 每个要点配具体例子
2. 使用数据支持观点
3. 提供可执行的建议
4. 避免空泛的陈述
```

**明确标准**：
```
我需要更精确的回答。

请按以下标准重新组织：
- 事实陈述要有来源
- 观点表达要有论证
- 建议给出要可执行
- 不确定的内容要标注
```

### 深度提升

```
你的回答停留在表面。

请深入分析：
1. 事物的本质是什么？
2. 底层逻辑是什么？
3. 有哪些深层次原因？
4. 长期影响是什么？

请挖掘更深的洞察。
```

### 实用性提升

```
你的回答很有道理，但不够实用。

请重新组织，提供：
1. 具体步骤（而非原则）
2. 工具推荐（而非概念）
3. 模板示例（而非框架）
4. 常见陷阱（而非理论）

让我能直接应用你的建议。
```

## 7.4 常见错误模式

### 错误 1：过度自信

**表现**：AI 对不确定的事情给出确定答案

**应对**：
```
你给出的答案很确定，但我怀疑这可能不是事实。

请：
1. 明确说明你的置信度
2. 列出可能的其他可能性
3. 建议如何验证

对于不确定的内容，请明确标注。
```

### 错误 2：幻觉内容

**表现**：编造不存在的事实、引用、数据

**应对**：
```
你提到的 [某内容] 我无法验证。

请：
1. 说明信息的来源
2. 如果不确定，请明确指出
3. 只基于确定的信息回答

请不要编造信息。
```

### 错误 3：过度概括

**表现**：用个别案例推导普遍规律

**应对**：
```
你的结论似乎基于有限的案例。

请重新考虑：
1. 这个结论的适用范围是什么？
2. 有哪些例外情况？
3. 什么情况下结论不成立？

请给出更细致的分析。
```

### 错误 4：忽略约束

**表现**：回答中没有遵守设定的约束条件

**应对**：
```
我在提问中明确要求：[重申约束]

但你的回答：[指出问题]

请严格遵循约束重新回答。
```

### 错误 5：逻辑跳跃

**表现**：推理过程缺失，直接给出结论

**应对**：
```
你的结论是 [结论]，
但我看不到推理过程。

请：
1. 逐步展示你的推理链
2. 说明每一步的逻辑
3. 指出可能的假设

让我能跟随你的思考。
```

## 系统化排查流程

```
问题：[描述遇到的问题]

请按以下流程帮我排查：

步骤 1：问题诊断
- 确切的问题是什么？
- 可能的原因有哪些？

步骤 2：分类处理
- 是理解偏差？ → 重新表述需求
- 是知识错误？ → 要求提供依据
- 是质量问题？ → 明确质量标准
- 是逻辑问题？ → 要求展示推理

步骤 3：验证确认
- 这个解决方案是否可行？
- 有哪些潜在风险？
- 如何验证解决效果？

步骤 4：预防措施
- 如何避免类似问题？
- 有哪些最佳实践？
```

## 本章要点

- 准确性检查：要求提供依据，明确置信度
- 理解偏差：重新表述，对比澄清
- 质量提升：增加约束，明确标准
- 错误模式：识别类型，针对性应对
