# 第二章：对话基础

## 2.1 提示词的结构

一个完整的提示词通常包含以下要素：

### 基础框架

```
[角色设定] + [任务描述] + [约束条件] + [输出要求]
```

### 实例分析

**基础提示词**：
```
写一份产品介绍
```

**优化后的提示词**：
```
[角色] 你是一位资深产品经理
[任务] 为一款智能手表撰写产品介绍
[内容要点]
- 健康监测功能
- 7 天续航
- 防水设计
- 目标用户：职场人士
[约束] 语言简洁专业，不超过 200 字
[格式] 包含标题和正文
```

---

## 2.2 清晰表达需求

### SMART 原则在提示词中的应用

| 原则 | 说明 | 示例 |
|------|------|------|
| Specific 具体的 | 明确要什么 | "写一份报告" → "写一份 Q3 销售数据分析报告" |
| Measurable 可衡量 | 设定量化标准 | "详细说明" → "分 5 个要点，每个不超过 50 字" |
| Achievable 可达成 | 任务在能力范围内 | 避免要求实时信息或机密内容 |
| Relevant 相关的 | 提供相关上下文 | 说明背景、目的、受众 |
| Time-bound 有时限 | 设定范围或长度 | "简短介绍" → "用 3-5 句话说明" |

### 清晰表达的技巧

1. **使用明确的动词**
   - ✅ 分析、总结、对比、生成
   - ❌ 弄一个、搞一下、看看

2. **避免模糊词汇**
   - ✅ "列出 3 个主要原因"
   - ❌ "说说原因"

3. **说明期望的输出**
   - ✅ "用表格呈现"
   - ❌ "整理一下"

## 2.3 提供充分上下文

### 为什么上下文重要

AI 的回答质量高度依赖你提供的信息。

### 上下文包含要素

**背景信息**：
```
我是一名高中数学老师，想向学生解释微积分的概念...
```

**目标受众**：
```
受众是 15 岁的学生，没有数学基础...
```

**已有内容**：
```
我已经写好了开头：xxx...
```

**期望方向**：
```
希望强调微积分在现实中的应用...
```

### 上下文示例

**上下文不足**：
```
帮我优化这段文案
[粘贴文案]
```

**上下文充分**：
```
请帮我优化这段电商产品文案：
[粘贴文案]

背景：这是一款便携式蓝牙耳机
目标用户：运动爱好者
当前问题：卖点不突出，缺乏吸引力
期望方向：强调音质、续航、佩戴舒适度
风格：简洁有力，有感染力
```

## 2.4 迭代优化对话

### 对话的本质

对话不是一次性的，而是迭代改进的过程。

```
初版提问 → 获得 → 评估 → 反馈 → 优化 → 满意结果
                结果   质量   调整   提问
```

### 迭代策略

1. **从宽泛到具体**
   ```
   第一轮：介绍一下机器学习
   第二轮：重点讲监督学习和无监督学习的区别
   第三轮：用具体的例子说明两者的应用场景
   ```

2. **利用 AI 的回答作为新提问的素材**
   ```
   你：什么是递归？
   AI：[给出解释]
   你：很好，用递归的方式实现斐波那契数列
   ```

3. **指出问题所在**
   ```
   这个回答太学术了，能用更通俗的语言重新解释吗？
   这个例子不恰当，换个生活中的例子
   这个结论有争议，请你从另一个角度分析
   ```

### 快速迭代模板

```
[反馈] 部分不错，但...
[指出问题] xxx 方面需要改进
[补充要求] 希望...
[再次提问] 请基于以上要求调整
```

---

## 实用检查清单

在发送提问前，问自己：

- [ ] 任务是否明确？
- [ ] 是否提供了足够的背景？
- [ ] 约束条件是否清晰？
- [ ] 输出格式是否说明？
- [ ] 是否在 AI 的能力范围内？

---

## 本章要点

- 提示词有清晰的结构框架
- 使用 SMART 原则让需求更明确
- 充分的上下文是高质量回答的前提
- 对话是迭代的，善用反馈优化
