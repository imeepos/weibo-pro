# 第四章：常用对话技巧

## 4.1 分步思考法

### 核心理念

引导 AI 展示推理过程，获得更可靠的答案。

### 基本格式

```
请逐步思考这个问题：
1. 先分析问题的核心
2. 考虑可能的角度
3. 给出你的结论
```

### 应用场景

**复杂问题分析**：
```
请逐步分析：为什么近年来远程办公越来越普及？

请按以下步骤思考：
1. 识别推动因素
2. 分析每个因素的作用
3. 考虑可能的挑战
4. 总结整体趋势
```

**数学问题**：
```
一个班有 30 名学生，其中 18 人喜欢篮球，15 人喜欢足球，8 人两者都喜欢。
问：有多少人两者都不喜欢？

请逐步求解：
1. 先明确已知条件
2. 用集合的方式表示
3. 逐步计算
4. 验证答案合理性
```

**决策分析**：
```
我正在考虑是否换工作，请帮我逐步分析：

当前工作情况：[描述]
新工作机会：[描述]

请从以下维度对比：
1. 薪资待遇
2. 职业发展
3. 工作生活平衡
4. 团队氛围
5. 风险评估

最后给出综合建议
```

## 4.2 角色扮演

### 核心理念

让 AI 扮演特定角色，获得专业视角和风格的回答。

### 应用场景

**专业咨询**：
```
你是一位心理咨询师。
我最近总是感到焦虑，失眠严重。
请以温和、专业的语气与我对话，
帮助我探索焦虑的可能原因。
```

**模拟面试**：
```
你是一位 Google 的面试官。
我正在应聘产品经理岗位。
请对我进行一场 30 分钟的模拟面试，
包括行为问题和情景问题。
面试后请给出反馈和改进建议。
```

**用户研究**：
```
请扮演以下用户群体，对我的产品原型给出反馈：

用户 A：65 岁退休教师，不太熟悉智能手机
用户 B：25 岁程序员，追求效率和个性化
用户 C：35 岁全职妈妈，时间碎片化

请分别以他们的口吻评价产品的易用性。
```

**苏格拉底式教学**：
```
你是一位苏格拉底式的导师。
我想学习[主题]。
请不要直接告诉我答案，
而是通过提问引导我自己思考。
```

## 4.3 思维链提示

### 核心理念

通过展示推理链条，引导 AI 进行更深层的思考。

### 标准思维链

```
请用思维链的方式回答：

问题：[你的问题]

请按以下格式回答：
思考过程：
[一步步的推理]

答案：
[最终结论]
```

### 高级应用：自我反思

```
请回答以下问题，然后自我检视：

问题：[你的问题]

回答：
[你的初始回答]

检视：
请批评你自己的回答：
1. 哪些地方可能不够准确？
2. 有哪些遗漏的视角？
3. 需要补充什么信息？

改进回答：
基于检视，给出改进后的答案
```

## 4.4 少样本学习

### 核心理念

通过少量示例让 AI 快速学习模式和风格。

### 基本模板

```
请仿照以下示例完成任务：

示例 1：
输入：[输入1]
输出：[输出1]

示例 2：
输入：[输入2]
输出：[输出2]

示例 3：
输入：[输入3]
输出：[输出3]

现在请处理：
输入：[新输入]
输出：
```

### 应用实例

**风格迁移**：
```
请将以下句子改写为正式商务邮件风格：

示例 1：
原文：你啥时候能把文件发我？
改写：请问您预计何时可以发送相关文件？

示例 2：
原文：这个方案我觉得不行
改写：经过审慎考虑，我认为该方案仍有待优化

现在请改写：
原文：明天开个会讨论一下
```

**格式转换**：
```
请将对话转换为 JSON 格式：

示例 1：
输入：张三：你好  李四：Hi
输出：
{
  "dialogue": [
    {"speaker": "张三", "content": "你好"},
    {"speaker": "李四", "content": "Hi"}
  ]
}

示例 2：
输入：A: 开始吧  B: 好的
输出：
{
  "dialogue": [
    {"speaker": "A", "content": "开始吧"},
    {"speaker": "B", "content": "好的"}
  ]
}

请转换：
输入：客服：有什么可以帮您？  用户：我想退款
```

## 4.5 约束与格式

### 约束类型

**长度约束**：
```
用 1 句话概括...
不超过 200 字...
每段 50 字左右...
```

**内容约束**：
```
只讨论...，不要涉及...
仅使用...来源的信息
避免使用...术语
```

**格式约束**：
```
以 Markdown 表格呈现
使用项目符号列表
采用对话体格式
```

**风格约束**：
```
使用正式的学术语言
用轻松幽默的口吻
以讲故事的风格
```

### 综合约束示例

```
请总结这篇文章：
[粘贴文章]

要求：
- 长度：150-200 字
- 结构：分 3 段（背景、内容、结论）
- 格式：每段以小标题开头
- 风格：简洁明了，避免学术术语
- 约束：不添加原文之外的信息
```

### 特定格式模板

**表格格式**：
```
请用表格形式对比 A 和 B：

| 维度 | A | B |
|------|---|---|
| 价格 | ? | ? |
| 性能 | ? | ? |
| ...  | ? | ? |
```

**JSON 格式**：
```
请以 JSON 格式输出：
{
  "summary": "摘要",
  "key_points": ["要点1", "要点2"],
  "conclusion": "结论"
}
```

**Markdown 格式**：
```
请按以下 Markdown 模板输出：

# [标题]

## 背景
[内容]

## 分析
[内容]

## 结论
[内容]
```

## 技巧组合策略

### 单任务组合

```
# 角色
你是一位资深编辑

# 任务
修改以下文章使其更简洁

# 要求
- 使用分步思考法：先分析问题，再修改
- 遵循少样本模式：参考示例风格
- 约束：删减 30% 字数，保持核心信息

# 示例风格
[给出简洁风格的示例]

# 原文
[待修改文本]
```

### 多任务分解

```
任务：分析竞品并给出建议

请分步完成：

步骤 1：列出竞品的主要功能
步骤 2：分析各自的优劣势
步骤 3：识别我们的机会点
步骤 4：给出 3 条具体建议

每步完成后请标注"---"并继续下一步
```
