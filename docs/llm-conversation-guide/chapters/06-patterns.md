# 第六章：经典对话模式

## 6.1 写作助手模式

### 基础写作流程

```
我需要写一篇文章。

请先作为写作顾问，帮我：
1. 明确文章目标和受众
2. 构思文章结构和要点
3. 确定写作风格和基调

完成这些后，我们再开始具体写作。
```

### 分阶段创作

**大纲阶段**：
```
主题：[主题]
类型：议论文/说明文/记叙文...
字数：[字数]

请先帮我拟定详细大纲，
包括每段的核心内容和要点。
```

**初稿阶段**：
```
基于以下大纲：
[粘贴大纲]

请撰写初稿。
要求：
- 每段展开 100-150 字
- 保持段落间逻辑连贯
- 使用过渡句连接
```

**修改阶段**：
```
[粘贴初稿]

请从以下角度修改：
1. 语言表达：更简洁有力
2. 结构优化：调整段落顺序
3. 论据强化：补充具体例子
4. 开头结尾：更有吸引力

每次修改一个方面，
让我确认后再进行下一方面。
```

### 特定类型写作

**邮件写作**：
```
场景：[描述场景]
收件人：[关系和职位]
目的：[想要达成什么]

请帮我写一封邮件。
要求：
- 语气：正式/友好/恳切...
- 结构：开场-正文-结尾-行动呼吁
- 长度：[字数]
```

**文案创作**：
```
产品：[产品描述]
卖点：[核心卖点]
目标用户：[用户画像]
使用场景：[场景描述]

请创作 3 条不同风格的广告文案：
1. 理性诉求型
2. 情感共鸣型
3. 简洁有力型
```

## 6.2 编程助手模式

### 代码理解

```
[粘贴代码]

请帮我：
1. 用通俗语言解释这段代码的功能
2. 分析其核心算法/逻辑
3. 标注关键代码行的作用
4. 指出可能存在的问题
```

### 代码生成

```
需求：[详细描述功能]

要求：
- 语言：Python/JavaScript/Java...
- 风格：函数式/面向对象...
- 约束：[性能/安全/兼容性要求]
- 测试：请同时生成单元测试

请先说明你的设计思路，
再给出代码实现。
```

### 代码调试

```
[粘贴代码]

这段代码存在以下问题：[描述 bug]

请：
1. 分析 bug 的可能原因
2. 给出修复方案
3. 解释为什么会出现这个 bug
4. 说明如何避免类似问题
```

### 代码审查

```
[粘贴代码]

请作为资深工程师进行代码审查：
1. 代码质量：可读性、可维护性
2. 性能问题：时间/空间复杂度
3. 安全隐患：输入验证、注入风险
4. 最佳实践：是否符合惯例

请给出具体改进建议。
```

### 技术选型

```
场景：[描述项目需求]
候选方案：
- A: [技术 A]
- B: [技术 B]
- C: [技术 C]

请从以下维度对比：
1. 学习曲线
2. 开发效率
3. 运行性能
4. 生态成熟度
5. 长期维护

给出推荐方案并说明理由。
```

## 6.3 分析研究员模式

### 数据分析

```
[粘贴数据]

请分析这组数据：
1. 识别关键趋势和模式
2. 找出异常值或特殊情况
3. 计算相关统计指标
4. 用可视化方式呈现（描述图表）
5. 给出你的洞察和建议
```

### 市场研究

```
产品：[产品描述]
目标市场：[市场定义]

请进行市场分析：
1. 市场规模和增长趋势
2. 主要竞争对手及定位
3. 用户画像和需求分析
4. 市场机会和威胁
5. 进入策略建议
```

### 文献综述

```
主题：[研究主题]

请提供文献综述框架：
1. 该领域的主要研究方向
2. 关键学者和代表性成果
3. 当前的争议和热点
4. 未来的研究方向
5. 建议阅读的核心文献
```

### SWOT 分析

```
分析对象：[公司/产品/项目]

请进行完整的 SWOT 分析：

优势（Strengths）：
- [列出内部优势]

劣势（Weaknesses）：
- [列出内部劣势]

机会（Opportunities）：
- [列出外部机会]

威胁（Threats）：
- [列出外部威胁]

基于分析，给出 3 条战略建议。
```

## 6.4 学习导师模式

### 概念解释

```
概念：[概念名称]

请用以下方式解释：
1. 一句话定义（10 岁能懂）
2. 更详细的说明
3. 具体例子
4. 常见误解
5. 相关概念推荐
```

### 学习路径规划

```
学习目标：[想学会什么]

当前水平：[描述背景]

请为我规划学习路径：
1. 分解为 4-6 个阶段
2. 每个阶段的具体目标
3. 推荐的学习资源
4. 预计时间安排
5. 检验学习成果的方法
```

### 习题生成

```
主题：[主题]
难度：初级/中级/高级
题型：选择题/填空题/简答题

请生成 5 道练习题，
并给出详细解答。
```

### 错题分析

```
题目：[题目内容]
我的解答：[错误答案]
正确答案：[正确答案]

请分析：
1. 我错在哪里？
2. 可能的原因是什么？
3. 如何避免类似错误？
4. 推荐 2 道相关练习题巩固
```

### 苏格拉底式辅导

```
我想学习：[主题]

请作为苏格拉底式的导师：
- 不要直接告诉我答案
- 通过提问引导我思考
- 在我困惑时给出提示
- 最后总结我们探讨的要点

让我们从这个问题开始：[第一个问题]
```

## 6.5 创意伙伴模式

### 头脑风暴

```
主题：[主题]

请进行头脑风暴：
1. 先列出 15 个创意点子
2. 不做评判，追求数量
3. 欢迎疯狂的想法
4. 再从中筛选最有潜力的 3 个
5. 对这 3 个进行深入展开
```

### 故事创作

```
类型：[类型：科幻/悬疑/爱情...]
背景：[故事背景设定]
主角：[主角设定]

请帮我：
1. 构思一个吸引人的故事梗概
2. 设计主要角色
3. 规划故事情节起伏
4. 创作第一章
5. 给出后续发展选项
```

### 命名与品牌

```
产品：[产品描述]
特点：[核心特点]
目标：[命名目标]

请提供 10 个命名建议，
涵盖以下风格：
- 2 个科技感
- 2 个文艺范
- 2 个亲民接地气
- 2 个国际化
- 2 个独特创新

对每个名字说明含义和联想。
```

### 创意挑战

```
给我一个创意挑战：

请设计一个限制条件，
让我用非常规方式解决 [问题]。

例如：
- "只能用 emoji 表达产品功能"
- "用 5 岁孩子的语言解释量子物理"
- "用武侠小说风格写技术文档"

请给出挑战，然后展示你的解决方案。
```

## 模式切换与组合

### 多模式协作

```
项目：[复杂项目]

让我们分阶段使用不同的模式：

阶段 1 - 研究员模式：
分析市场和竞争环境

阶段 2 - 创意伙伴模式：
头脑风暴产品概念

阶段 3 - 编程助手模式：
设计技术架构

阶段 4 - 写作助手模式：
撰写项目文档

每完成一个阶段，请总结要点，
然后我们进入下一阶段。
```

### 模式融合

```
任务：[任务]

请同时运用：
- 研究员的分析能力
- 创意伙伴的想象力
- 导师的解释能力

目标是：[具体目标]

请给出融合多种视角的答案。
```

## 本章要点

- 写作助手：从规划到创作到修改
- 编程助手：理解、生成、调试、审查
- 分析研究员：数据、市场、文献、SWOT
- 学习导师：解释、规划、练习、引导
- 创意伙伴：头脑风暴、故事、命名、挑战
