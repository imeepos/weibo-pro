# 第五章：高级策略

## 5.1 复杂任务分解

### 核心理念

将大任务拆解为可管理的小任务，逐步完成。

### 分解策略

**层级分解**：
```
主任务：写一份商业计划书

第一层分解：
1. 市场分析
2. 产品介绍
3. 运营计划
4. 财务预测

第二层分解（以市场分析为例）：
1.1 目标市场规模
1.2 竞争对手分析
1.3 用户需求调研
1.4 市场趋势判断
```

### 交互式分解

```
我需要完成 [大任务]。

请先帮我：
1. 将这个任务分解为主要的子任务
2. 按优先级排序
3. 标注每个子任务的预计难度

完成后，我们从第一个子任务开始。
```

### 实例：完整项目流程

```
我想开发一个美食推荐 APP。

请帮我：
1. 需求分析阶段
   - 列出核心功能需求
   - 定义用户画像
   - 明确竞品差异点

2. 设计阶段
   - 产品架构设计
   - 用户流程规划
   - UI/UX 要点

3. 开发规划
   - 技术栈选择建议
   - 开发里程碑
   - 风险评估

4. 运营策略
   - 冷启动方案
   - 用户增长策略
   - 商业化路径

请按阶段逐一详细说明。
```

## 5.2 多轮对话管理

### 核心理念

保持对话的连贯性和上下文的累积。

### 对话状态管理

**建立对话框架**：
```
让我们就 [主题] 进行深入讨论。

请按以下结构进行：
1. 你先提出 3 个关键问题帮我梳理思路
2. 我回答后，你给出分析
3. 我们共同完善方案
4. 最后总结共识

每轮对话开始时，请简要回顾上一轮的要点。
```

### 长对话技巧

**阶段性总结**：
```
我们已经讨论了 [内容A] 和 [内容B]。

请先总结目前的共识，
然后我们继续讨论 [下一主题]。
```

**回溯与调整**：
```
回顾之前的讨论，我发现 [观点] 可能有问题。

请帮我：
1. 找出这个问题
2. 分析如何调整
3. 更新我们的方案
```

**分支探索**：
```
目前有两个方向：A 和 B。

让我们先探索方向 A：
[深入讨论 A]

暂停方向 A，现在探索方向 B：
[深入讨论 B]

请对比分析，给出建议。
```

## 5.3 知识检索结合

### 核心理念

将 AI 的通用知识与你提供的具体信息结合。

### 信息注入

**文档分析**：
```
[粘贴文档内容]

基于以上文档，请回答：
1. 核心观点是什么？
2. 主要论据有哪些？
3. 你认为这篇文档的可信度如何？
```

**知识库构建**：
```
以下是我们产品的技术文档：
[粘贴文档]

以下是我们的常见问题解答：
[粘贴 FAQ]

请基于这些信息回答用户问题：
[用户问题]

如果信息不足，请明确指出缺少什么。
```

### 迭代式检索

```
主题：[复杂主题]

第一轮：请给我这个主题的框架性介绍
[阅读回答]

第二轮：请深入讲解 [特定子话题]
[阅读回答]

第三轮：请用实例说明 [具体概念]
[阅读回答]

第四轮：请总结 3 个最重要的要点
```

## 5.4 创造性激发

### 核心技巧

**反向思考**：
```
我想 [目标]。

请先从相反的角度思考：
如果要让 [目标] 失败，应该怎么做？

请列出 5 个会导致失败的做法，
然后分析如何避免这些问题。
```

**强制联想**：
```
产品 A：咖啡
产品 B：音响

请强行关联，创造一个融合两者的新产品概念。
要求：
- 有创新性
- 有可行性
- 有商业价值
```

**限制激发创意**：
```
常规方案：[描述常规做法]

现在请给出一个在以下限制下的替代方案：
- 预算只有原来的 10%
- 团队只有 1 人
- 时间只有 1 周

限制条件往往激发创意，请大胆想象。
```

**创意矩阵**：
```
维度：
- 风格：简约/华丽/复古/未来
- 受众：儿童/成人/老人
- 场景：家庭/办公/户外

请从矩阵中选择 3 个有创意的组合，
为每个组合生成产品概念。
```

## 5.5 逻辑推理引导

### 批判性思维

**观点论证**：
```
观点：[某个有争议的观点]

请按以下结构分析：
1. 支持这个观点的论据
2. 反对这个观点的论据
3. 每个论据的可信度评估
4. 你的综合判断

请保持客观中立。
```

**假设检验**：
```
假设：[某个假设]

请设计验证方案：
1. 如何定义可观测的指标？
2. 需要收集什么数据？
3. 如何控制其他变量？
4. 什么样的结果支持/反驳假设？
```

**因果推理**：
```
现象：[观察到现象]

可能原因：
请列出 5 个可能的原因，
并按可能性排序。

对每个原因：
- 分析其合理性
- 说明如何验证
- 给出排除/确认的方法
```

**逻辑谬误识别**：
```
以下论证是否存在逻辑谬误？
[粘贴论证]

请检查：
1. 是否有循环论证？
2. 是否有以偏概全？
3. 是否有滑坡谬误？
4. 是否有因果谬误？
5. 其他谬误？

请指出问题并解释为什么是谬误。
```

## 综合应用示例

### 复杂决策流程

```
我需要做一个重要决策：[描述决策情境]

请引导我完成以下流程：

第一阶段：问题定义
- 核心问题是什么？
- 有哪些可能的选项？
- 每个选项的关键考量因素是什么？

第二阶段：信息收集
- 我需要哪些信息来帮助决策？
- 这些信息如何获取？
- 请帮我设计信息收集清单

第三阶段：分析评估
- 请用决策矩阵分析法评估各选项
- 考虑每个因素的重要性权重
- 量化评分

第四阶段：风险评估
- 每个选项的潜在风险
- 风险发生的概率
- 风险应对方案

第五阶段：决策总结
- 综合评估结果
- 给出推荐选项
- 说明理由和保留意见

请按阶段逐一引导我完成。
```

## 本章要点

- 任务分解：化繁为简，逐步推进
- 对话管理：保持连贯，适时总结
- 知识结合：内外信息，综合运用
- 创造激发：反向思考，限制创新
- 逻辑引导：批判思维，严谨推理
