# 第三章：提示词工程原则

## 3.1 明确性原则

### 核心理念

消除歧义，让 AI 准确理解你的意图。

### 实践方法

**1. 避免代词指代不清**

❌ 模糊：
```
解释它为什么会这样
```

✅ 明确：
```
解释为什么这段代码会导致内存泄漏
```

**2. 避免多义词引起误解**

❌ 模糊：
```
帮我检查这个
```

✅ 明确：
```
帮我检查这段 Python 代码的语法错误
```

**3. 一次性说明完整需求**

❌ 碎片化：
```
写个介绍
要针对学生
关于历史课的
```

✅ 完整表达：
```
为高中历史课撰写一段关于文艺复兴的介绍，300 字左右，面向 15 岁学生
```

---

## 3.2 具体性原则

### 核心理念

越具体的指令，越能得到预期的结果。

### 实践方法

**1. 数量化要求**

```
列出 5 个改进建议
分为 3 个部分进行说明
每段不超过 100 字
```

**2. 明确范围**

```
仅讨论 Python 3.x 版本
只考虑中国市场的情况
聚焦于用户体验问题
```

**3. 指定格式**

```
使用 Markdown 表格
以项目符号列表呈现
采用对话体形式
```

### 具体性对比

| 维度 | 不够具体 | 足够具体 |
|------|----------|----------|
| 长度 | "写详细点" | "写 500 字左右" |
| 结构 | "整理一下" | "分 5 个部分，每个包含标题和内容" |
| 风格 | "写得专业点" | "使用学术风格，包含专业术语，避免口语化" |
| 受众 | "给普通人看" | "面向没有技术背景的职场人士" |

---

## 3.3 结构化原则

### 核心理念

用清晰的结构组织提示词，提高可读性和可理解性。

### 推荐结构模板

```
# 角色
你是一位 [角色描述]

# 任务
[具体任务说明]

# 要求
1. [要求1]
2. [要求2]
3. [要求3]

# 输出格式
[格式说明]

# 约束
[约束条件]
```

### 结构化示例

```
你是一位资深的美食评论家。

请为以下餐厅撰写一篇评论文稿：
- 餐厅名称：江南小厨
- 菜系：江浙菜
- 人均消费：150 元
- 特色：环境优雅，招牌菜是东坡肉

要求：
1. 200 字左右
2. 突出菜品特色
3. 包含环境描写
4. 语言优雅生动

输出格式：
标题 + 正文（分段落）
```

## 3.4 示例驱动原则

### 核心理念

通过示例让 AI 理解你期望的输出模式。

### 示例的作用

- 明确格式要求
- 展示风格特征
- 说明复杂规则
- 降低理解偏差

### 少样本学习（Few-Shot Learning）

**提供 2-3 个示例**：

```
请仿照以下格式生成产品描述：

示例 1：
名称：降噪耳机
特点：主动降噪，30 小时续航
描述：这款耳机采用先进的主动降噪技术，让你随时随地沉浸在纯净音乐中。30 小时超长续航，陪伴你的每一次旅程。

示例 2：
名称：运动手表
特点：心率监测，防水设计
描述：全天候心率监测，守护你的运动健康。50 米防水设计，无惧汗水与雨水，释放运动激情。

现在请为"智能保温杯"（特点：温度显示，12 小时保温）生成产品描述。
```

### 示例设计原则

1. **相关性**：示例与目标任务相似
2. **一致性**：多个示例保持相同模式
3. **简洁性**：每个示例突出核心特征
4. **完整性**：示例覆盖所有关键要素

## 3.5 角色设定原则

### 核心理念

通过设定角色，让 AI 以特定视角和风格回应。

### 常用角色模板

**专业角色**：
```
你是一位拥有 10 年经验的资深产品经理...
你是一位专业的心理咨询师...
你是一位获得普利策奖的记者...
```

**功能角色**：
```
你是一位擅长简化复杂概念的科普作家...
你是一位注重用户体验的交互设计师...
你是一位善于辩论的批判性思维导师...
```

**创意角色**：
```
你是一位充满想象力的儿童文学作家...
你是一位幽默风趣的脱口秀演员...
你是一位富有诗意的故事讲述者...
```

### 角色设定框架

```
你是一位 [角色名称]，
具备 [专业背景/经验]，
擅长 [核心能力]，
以 [风格特点] 的方式沟通。
```

### 角色设定示例

**基础角色**：
```
你是一位律师
```

**增强角色**：
```
你是一位擅长知识产权法的资深律师，
拥有 15 年从业经验，
曾处理过 200+ 专利诉讼案件，
善于用清晰通俗的语言解释复杂的法律概念。
```

### 多角色对话

```
请模拟以下对话：

张三（乐观派）：认为远程办公提高效率
李四（保守派）：认为面对面沟通不可替代

请他们就"混合办公模式"进行辩论，
每人发言 3 轮，每轮 100 字左右。
```

## 原则综合运用

### 组合示例

```
# 角色
你是一位有 20 年经验的数据分析师，擅长向非技术背景的管理者解释数据洞察。

# 任务
分析以下销售数据，提供业务建议

# 数据
[粘贴数据]

# 要求
1. 识别 3 个关键趋势
2. 每个趋势给出具体建议
3. 使用图表说明数据关系
4. 避免技术术语

# 输出格式
## 趋势分析
[内容]

## 行动建议
[内容]

## 数据图表
[用 ASCII 或描述呈现图表]

# 示例输出风格
趋势一：年轻用户购买力增长
数据显示：18-25 岁用户占比从 15% 上升至 28%
建议：增加社交媒体营销投入，针对年轻群体优化产品设计
```

---

## 本章要点

- 明确性：消除歧义，准确传达意图
- 具体性：量化要求，限定范围
- 结构化：用清晰框架组织提示词
- 示例驱动：用实例展示期望模式
- 角色设定：塑造回应风格和视角
