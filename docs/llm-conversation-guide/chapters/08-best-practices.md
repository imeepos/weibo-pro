# 第八章：最佳实践

## 8.1 不同场景的对话策略

### 场景 1：快速获取信息

**适用情况**：简单问答、事实查询

**策略**：
```
直接、简洁的提问
- 单一问题
- 明确范围
- 必要时要求来源
```

**示例**：
```
Python 中 list 和 tuple 的主要区别是什么？
请用表格对比，不超过 5 点。
```

---

### 场景 2：深度学习和理解

**适用情况**：学习新概念、掌握新技能

**策略**：
```
分层递进式提问
1. 先建立整体认知框架
2. 再深入具体细节
3. 通过实例巩固理解
4. 最后总结提炼
```

**示例**：
```
我想学习机器学习。

第一层：请介绍机器学习的整体框架和主要分支
第二层：深入讲解监督学习的核心概念
第三层：用具体例子说明分类和回归的区别
第四层：总结初学者的学习路径建议
```

---

### 场景 3：创意工作

**适用情况**：文案创作、设计构思、头脑风暴

**策略**：
```
发散收敛结合
1. 先发散：大量生成创意
2. 再收敛：筛选最有价值的
3. 深化：对选中方案深入展开
4. 优化：迭代改进细节
```

**示例**：
```
为咖啡品牌设计 slogan。

阶段 1：先给我 20 个不同方向的创意
阶段 2：我选择喜欢的方向，深入生成
阶段 3：对确定的方案进行优化
阶段 4：提供不同长度的变体
```

---

### 场景 4：问题解决

**适用情况**：调试代码、排查故障、决策分析

**策略**：
```
诊断-分析-解决
1. 明确问题本质
2. 分析可能原因
3. 设计解决方案
4. 评估和选择
```

**示例**：
```
我的网站加载很慢。

请帮我：
1. 诊断：分析可能的原因
2. 排序：按可能性排序
3. 方案：针对每个原因给出解决方案
4. 验证：说明如何验证问题已解决
```

---

### 场景 5：复杂任务

**适用情况**：项目规划、系统设计、研究报告

**策略**：
```
模块化分解
1. 拆解为独立子任务
2. 明确子任务间依赖关系
3. 逐个完成子任务
4. 整合形成完整方案
```

**示例**：
```
我想做一个美食推荐 APP。

请先帮我把这个项目分解为模块，
然后我们逐个模块深入讨论。
```

## 8.2 效率优化技巧

### 提示词复用

**创建模板库**：
```
# [模板名称]

## 适用场景
[什么时候用]

## 提示词模板
```
[固定部分]
[可变部分：XXX]
[固定部分]
```

## 使用示例
[一个实际使用的例子]
```

### 批量处理

**相似任务批量处理**：
```
我有多个类似的问题需要处理。

问题列表：
1. [问题1]
2. [问题2]
3. [问题3]
...

请对每个问题：
1. 给出简洁回答（50字内）
2. 标注难度评级
3. 提供扩展学习建议（如有）
```

### 快速迭代

```
# 快速迭代模板

第一版：
[简洁提问]

基于第一版回答：
[指出1-2个需要改进的点]

第二版：
[要求改进]

重复直到满意。
```

## 8.3 安全与隐私注意

### 不应分享的信息

```
❌ 不要分享：
- 密码、密钥、token
- 个人身份信息（身份证、银行卡）
- 他人隐私信息
- 公司机密数据
- 法律禁止的内容
```

### 数据脱敏

```
✅ 脱敏后再分享：
- 姓名：张三 → 用户A
- 电话：138xxxx1234
- 邮箱：user@xxx.com
- 地址：某市某区
- 数据：使用模拟数据
```

### 法律和伦理边界

```
⚠️ 谨慎处理的场景：
- 医疗诊断：AI 不能替代专业医生
- 法律建议：需要专业律师确认
- 财务决策：需要自己的判断和验证
- 投资建议：仅供参考，风险自负
```

## 8.4 持续学习方法

### 记录有效提示词

**建立个人提示词库**：
```
## 写作 - 文章大纲

你是一位专业的文章结构设计师。

主题：[主题]
类型：[类型]
字数：[字数]

请设计文章大纲：
1. 引人入胜的开头
2. 清晰的主体结构（3-5个部分）
3. 有力的结尾

每个部分简要说明核心内容。
```

### 复盘总结

```
任务完成后，请帮我复盘：

1. 这个提示词哪里做得好？
2. 哪里可以改进？
3. 有什么可以复用的模式？
4. 下次如何提问更高效？

请总结成可复用的提示词模板。
```

### 学习他人经验

**分析优质提示词**：
```
这个提示词：[粘贴]

请分析：
1. 它为什么有效？
2. 使用了哪些技巧？
3. 我可以如何借鉴？
4. 如何改进以适应我的需求？
```

## 综合实例：完整工作流

### 项目：撰写技术博客

```
# 第一阶段：规划

我想写一篇关于 [技术主题] 的技术博客。

请作为技术写作顾问：
1. 分析目标读者的技术背景
2. 确定文章的深度和广度
3. 设计文章结构和要点
4. 建议合适的代码示例

# 第二阶段：创作

基于上述规划，请：
1. 撰写引人入胜的开头
2. 逐步展开各部分内容
3. 插入恰当的代码示例
4. 确保段落间过渡流畅

每写完一部分，让我审阅后再继续。

# 第三阶段：优化

[粘贴初稿]

请从以下角度优化：
1. 技术准确性
2. 表达清晰度
3. 代码可读性
4. 整体结构

# 第四阶段：润色

[粘贴优化后的稿件]

请进行最终润色：
1. 标题吸引力
2. 开头和结尾
3. 语言流畅度
4. 格式统一性

# 第五阶段：总结

请总结这篇文章的写作经验：
1. 最有效的提示词策略
2. 可以复用的写作模式
3. 需要注意的问题
4. 形成可复用的模板
```

## 结语

高效与 AI 对话的核心在于：

1. **理解 AI 的本质**：它不是全知全能的助手，而是需要明确引导的工具

2. **掌握核心原则**：明确、具体、结构化、示例驱动

3. **灵活运用技巧**：根据场景选择合适的对话策略

4. **保持批判思维**：验证 AI 的回答，不盲目接受

5. **持续优化改进**：总结经验，建立自己的提示词库

记住：好的对话是双方的努力——清晰的提问 + 积极的反馈 = 高效的结果。
