## 工作流程

### 一、每日数据完整性审核

#### 1.1 获取数据
- 登录系统查看当日爬取结果
- 下载需要审核的事件数据
- 确认数据时间范围

#### 1.2 完整性检查
| 检查项 | 标准 | 记录 |
|-------|------|------|
| 数据总量 | 与预期基本一致（±10%） | |
| 时间覆盖 | 无明显时间段缺失 | |
| 字段完整 | 必填字段无空值 | |
| 去重情况 | 重复数据<1% | |

#### 1.3 异常处理
- 数据量异常偏低 → 标记问题，通知爬取组
- 时间段缺失 → 记录缺失范围，安排补爬
- 字段异常 → 统计异常类型和数量

### 二、NLP结果复核

#### 2.1 情感分析审核
随机抽取20条数据进行人工复核：

| 样本 | 系统判定 | 人工判定 | 是否一致 | 备注 |
|-----|---------|---------|---------|------|
| 1 | 积极/中性/消极 | 积极/中性/消极 | ✓/✗ | |
| 2 | ... | ... | ... | |

准确率计算：一致数 / 总样本数

#### 2.2 关键词提取审核
- 检查Top关键词是否与事件相关
- 验证关键词权重是否合理
- 识别无意义词（停用词漏网）

#### 2.3 实体识别审核
- 人名、地名、机构名识别准确性
- 实体消歧是否正确
- 新实体的识别情况

### 三、可视化数据验证

#### 3.1 趋势图验证
- 检查数据点与原始数据对应
- 验证峰值、谷值是否合理
- 检查时间轴连续性

#### 3.2 词云验证
- 确认词频统计准确
- 检查词云显示与数据一致
- 验证词语过滤效果

#### 3.3 分布图验证
- 验证分类统计准确性
- 检查百分比总和是否为100%
- 确认样本数量标注正确

### 四、问题整理与报告

#### 4.1 问题分级

| 级别 | 描述 | 处理时限 |
|-----|------|---------|
| 严重 | 影响核心功能，数据完全不可用 | 立即 |
| 高 | 影响主要功能，数据部分可用 | 当日 |
| 中 | 影响次要功能，有替代方案 | 3日内 |
| 低 | 体验问题，不影响功能 | 1周内 |

#### 4.2 问题记录模板

```
问题编号：DATA-YYYYMMDD-001
发现时间：
发现人：
问题描述：
影响范围：
严重程度：
复现步骤：
截图/数据：
```

#### 4.3 每日报告内容
- 当日审核事件数量
- 数据完整性情况
- NLP准确率统计
- 发现问题汇总
- 改进建议

## 注意事项

1. **审核质量**
   - 严格按照标准执行
   - 发现问题及时记录
   - 复核抽样要随机

2. **效率要求**
   - 每日审核应在数据产出后24小时内完成
   - 批量审核时可使用工具辅助
   - 重点关注异常数据

3. **沟通协作**
   - 与爬取组保持数据问题沟通
   - 与技术组反馈系统Bug
   - 与优化组分享发现

4. **持续改进**
   - 总结常见问题类型
   - 提出审核流程优化建议
   - 积累审核经验知识库
