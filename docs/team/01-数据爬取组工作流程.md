## 工作流程

### 一、账号登录管理

#### 1.1 账号准备
- 准备有效的微博账号（建议使用小号，避免主账号风险）
- 确保账号状态正常，未被封禁或限制
- 记录账号信息（用户名、密码、Cookie有效期）

#### 1.2 登录流程
1. 打开系统登录页面
2. 输入微博账号凭证
3. 完成人机验证（如需要）
4. 确认登录成功
5. 检查Cookie有效期

#### 1.3 账号维护
- 每日检查账号状态
- 发现登录异常及时更换账号
- 记录账号问题日志

### 二、事件录入

#### 2.1 事件信息收集
- 确定事件名称
- 收集事件相关关键词
- 确定时间范围
- 明确数据类型（微博、评论、转发等）

#### 2.2 事件创建流程
1. 进入事件管理页面
2. 点击"新建事件"
3. 填写事件信息：
   - 事件名称（清晰描述）
   - 关键词（核心词+相关词，用逗号分隔）
   - 开始时间
   - 结束时间（预计）
   - 数据来源选择
4. 确认创建

#### 2.3 任务启动
1. 选择已创建事件
2. 配置爬取参数：
   - 爬取频率
   - 每日数据量上限
   - 数据类型选择
3. 启动爬取任务
4. 监控任务状态

### 三、日常操作规范

#### 3.1 每日检查清单
- [ ] 检查账号登录状态
- [ ] 查看待处理事件
- [ ] 确认爬取任务正常运行
- [ ] 查看错误日志

#### 3.2 任务监控
- 实时关注爬取进度
- 发现异常及时处理
- 记录爬取数据量

#### 3.3 问题处理
| 问题类型 | 处理方式 |
|---------|---------|
| 登录失败 | 检查账号状态，更换账号 |
| 爬取中断 | 查看错误日志，重启任务 |
| 数据量为0 | 检查关键词是否正确 |
| 频率限制 | 降低爬取频率，更换账号 |

---

## 注意事项

1. **账号安全**
   - 不要在公共设备保存密码
   - 定期更换账号
   - 避免使用主账号

2. **数据合规**
   - 仅采集公开数据
   - 遵守平台使用规则
   - 注意数据使用边界

3. **操作规范**
   - 按流程操作，不跳步骤
   - 及时记录问题
   - 保持与审核组沟通

4. **紧急情况**
   - 爬取完全停止 → 立即报告组长
   - 批量账号失效 → 启动备用账号
   - 系统无法访问 → 联系技术组
