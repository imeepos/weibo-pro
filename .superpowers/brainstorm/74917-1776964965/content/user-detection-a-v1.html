中列：用户 dossier

这里不是“详情弹窗”，而是一个案件档案页：账号基本面、主页历史发帖、行为时间线、代表性证据全部汇聚在中间。
账号基本面 昵称 / 认证 / 粉丝 / 关注 / 地域 / 主页简介 / 注册时长 / 近期活跃时段
风险来源拆解 事件内风险分、负向倾向、异常活跃、传播放大、跨事件参与、关系异常
主页历史发帖回溯近 30 / 90 天
行为时间线 按天或按事件看：发帖峰值、议题切换、情绪反转、互动异常峰值。
主题簇分布 体育、社会热点、地域议题、情绪化评论、营销型内容占比。
叙事风格剖面 煽动性、讽刺性、搬运性、对立构造、立场漂移、常用措辞模板。
证据样本AI 前必须可追溯
事件内高风险样本 为什么这个账号会被拉进高危队列，至少要有 3-5 条事件内代表贴文。
主页历史代表贴文 按议题和时间分层抽样，不是简单抓一堆最近帖子直接喂给模型。

图谱节点示例 Persona: 用户 A；Memory: 身份标签、议题偏好、情绪特征、行为模式、关键事件、关系账号。
全量图谱入口 支持切到“所有已蒸馏用户图谱视图”，看哪些用户共用议题、风格、关系链、风险模式。
这版的关键判断是：用户检测页面的主任务不再是“浏览用户”，而是“把一个高危候选转化成可复用的角色画像资产”。 也就是说，中列要承载调查过程，右列要承载 AI 蒸馏结果和知识沉淀，最后还要能跳到全量图谱总览。
