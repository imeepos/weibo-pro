# Weibo-Pro 舆情监控大屏 - 用户操作手册

## 系统简介

Weibo-Pro 舆情监控大屏是一个专业的微博舆情分析平台，提供实时数据可视化、事件深度分析、用户关系网络、工作流编排等功能。

### 技术特点
- **30+ 数据可视化组件** - 图表、词云、3D 关系网络
- **实时数据推送** - WebSocket 支持
- **灵活布局系统** - 自定义大屏编排
- **SDK 驱动架构** - 类型安全的前后端通信

---

## 二、核心功能模块

### 2.1 数据总览 (`/index` 或 `/data-overview`)

**功能概述**
实时展示微博舆情数据的全面概览，包含统计指标、热点事件、情感分布、地理分布等。

**主要展示内容**

| 区域 | 组件 | 说明 |
|------|------|------|
| 顶部统计卡片 | MetricCard | 帖子总数、用户数、事件数等关键指标，带迷你趋势图 |
| 左上 | HotEventsList | 热门事件列表，点击跳转详情 |
| 右上 | WordCloudChart | 关键词云，高频词汇可视化 |
| 中左 | GeographicChart | 全国地理热力图，鼠标悬停查看各省市数据 |
| 中右 | UserRelationOverview | 用户关系网络概览图 |
| 底部 | SentimentCurveChart | 情感趋势曲线图 |
| 右下 | EventTypeBarChart | 事件类型分布柱状图 |

**交互操作**
- 点击热门事件跳转到事件详情页
- 鼠标悬停图表查看详细数据
- 时间范围筛选器影响所有图表数据

### 2.2 事件分析 (`/event-analysis`)

**功能概述**
查看和分析所有舆情事件列表，支持搜索、筛选、分页。

**页面布局**
```
┌─────────────────────────────────────────────────────────┐
│  事件分析                              [搜索框] [筛选]  │
├─────────────────────────────────────────────────────────┤
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐  统计指标卡片         │
│  │事件数│ │帖子数│ │用户数│ │平均热度│                     │
│  └─────┘ └─────┘ └─────┘ └─────┘                       │
├─────────────────────────────────────────────────────────┤
│  事件列表                                              │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 📌 事件标题                    [✏️] 热度: ★★★★  │  │
│  │    关键词: xxx, xxx          情感: 😊 趋势: ↗️   │  │
│  └──────────────────────────────────────────────────┘  │
│  [< 上一页] 1 2 3 ... 10 [下一页 >]                    │
└─────────────────────────────────────────────────────────┘
```

**核心功能**
1. **搜索** - 输入关键词搜索事件（防抖 300ms）
2. **筛选** - 按事件类型、情感类别筛选
3. **编辑关键词** - 点击 ✏️ 图标打开编辑对话框
4. **分页** - 支持页码跳转

**编辑关键词操作**
1. 点击事件卡片右上角的 ✏️ 图标
2. 在对话框中删除关键词（点击 ×）或添加新关键词
3. 点击"保存"提交修改

**编辑器布局**
```
┌─────────────────────────────────────────────────────────┐
│  工作流编辑器                    [保存] [执行] [返回]   │
├──────────────┬──────────────────────────────────────────┤
│              │                                          │
│  节点面板    │           画布区域                        │
│              │                                          │
│  📥 输入     │     ┌─────┐      ┌─────┐                │

│  📤 输出     │     └─────┘      └─────┘                │
```

**基本操作**
1. **添加节点** - 从左侧面板拖拽节点到画布
2. **连接节点** - 从节点输出端口拖拽连线到另一节点输入端口

5. **保存工作流** - 点击"保存"按钮
6. **执行工作流** - 点击"执行"按钮查看运行结果

**节点类型**

## 三、通用操作说明

### 3.1 时间范围筛选

**位置**
页面顶部或右上角的时间选择器

**选项**
| 选项 | 范围 |
|------|------|
| 今天 | 当日 00:00 至今 |
| 最近 7 天 | 过去 7 天 |
| 最近 30 天 | 过去 30 天 |
| 自定义 | 自定义起止日期 |

**影响范围**
时间筛选器会影响页面内所有数据请求，包括图表、列表等。

---

### 3.2 数据刷新

**手动刷新**
- 点击页面右上角的 🔄 刷新按钮
- 或按浏览器刷新键 F5

**自动刷新**
- 部分页面支持自动刷新（如爬虫控制面板）
- 数据总览页面通过 WebSocket 实时更新

---

### 3.3 数据导出

**图表导出**
1. 右键点击图表
2. 选择"另存为图片"
3. 选择 PNG 格式保存

**数据导出**
部分列表页面支持导出功能：
- 点击"导出"按钮
- 选择导出格式（CSV/Excel）
- 下载文件

---

### 3.4 全屏模式

**进入全屏**
- 按 `F11` 键
- 或点击页面全屏按钮（如有）

**退出全屏**
- 按 `ESC` 键
- 或按 `F11` 键切换

## 四、常见问题解答 (FAQ)

### 4.1 连接问题

**Q: WebSocket 连接失败怎么办？**
A: 请检查：
1. 确认后端 API 服务正常运行
2. 检查网络连接是否正常
3. 清除浏览器缓存后重试
4. 联系管理员检查服务状态

**Q: 数据加载超时？**
A: 请尝试：
1. 刷新页面重新加载
2. 检查网络连接
3. 缩小时间范围减少数据量
4. 稍后重试

---

### 4.2 显示问题

**Q: 图表显示异常？**
A: 请尝试：
1. 刷新页面
2. 清除浏览器缓存
3. 检查浏览器是否为兼容版本
4. 尝试使用其他浏览器

**Q: 3D 组件无法加载？**
A: 请检查：
1. 浏览器是否支持 WebGL
2. 显卡驱动是否正常
3. 尝试更新浏览器版本

---

### 4.3 操作问题

**Q: 工作流编辑器如何连接节点？**
A: 操作步骤：
1. 从源节点的右侧输出端口按住鼠标左键
2. 拖拽到目标节点的左侧输入端口
3. 松开鼠标完成连接
4. 右键连线可删除连接

**Q: 布局保存失败？**
A: 请检查：
1. 确认布局名称不为空
2. 检查网络连接
3. 刷新页面后重试

**Q: 如何批量操作？**
A: 目前支持批量操作的页面：
- 爬虫控制面板的批量 NLP 触发（批量输入帖子 ID）
- 批量 ID 支持逗号或换行分隔

---

### 4.4 数据问题

**Q: 数据更新不及时？**
A: 请确认：
1. 检查 WebSocket 连接状态
2. 手动点击刷新按钮
3. 检查爬虫任务是否正常运行
4. 确认时间范围设置是否正确

**Q: 历史数据查询？**
A: 使用时间范围筛选器：
1. 选择"自定义"选项
2. 设置起止日期
3. 点击应用
