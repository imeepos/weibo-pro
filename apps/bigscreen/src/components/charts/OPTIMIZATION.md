# UserRelationOverview 可视化优化

## 优化内容

### 1. 分层渲染策略（支持百万级节点）

**文件**: `LayeredRenderer.ts`

- **核心层**（前1000节点）：完整渲染高影响力节点
- **中间层**（1000-10000节点）：简化渲染中等影响力节点
- **背景层**（10000+节点）：聚合为热力图（未来扩展）

自动根据节点数量选择渲染策略，无需手动配置。

### 2. 节点大小优化

**文件**: `NodeSizeCalculator.ts`

- 使用指数曲线 `Math.pow(score, 0.7)` 增强视觉差异
- 扩大范围：2-35（原3-25）
- 高影响力节点更突出

### 3. 线条动态化

**文件**: `UserRelationGraph3D.tsx`

- **粗细**：根据权重动态调整（0.5-3.5）
- **透明度**：根据权重动态调整（0.3-1.0）
- 强关系更粗更明显，弱关系更细更透明

### 4. 颜色优化

**文件**: `UserRelationGraph3D.utils.ts`

- 提高亮度和对比度
- 节点颜色：`#ff5555`, `#5599ff`, `#dd88ff`, `#55dd88`
- 边颜色：`#ff66aa`, `#5599ff`, `#aa77ff`, `#ffaa44`

### 5. 性能提升

**文件**: `UserRelationOverview.tsx`

- 节点限制提升：1000 → 100000
- 分层渲染自动优化性能
- 启用性能监控面板（显示分层状态）

## 使用方式

无需修改调用代码，优化自动生效：

```tsx
<UserRelationOverview className="h-full" />
```

## 性能指标

- **1000节点以下**：全渲染，60fps
- **1000-10000节点**：核心+中间层，45-60fps
- **10000+节点**：仅核心层，30-60fps

分层渲染确保即使百万级数据也能流畅展示核心关系。
